- 编辑器操作的“更多”展开后变为“更少”，收起后恢复“更多”；变量类继续没有这组附加功能和“更多”。
- 主页结果框增加小号“输出结果”标题。点击共享按钮外的任意区域隐藏整个框，不会因页面切换或前台恢复重新出现；下一次运行显示新结果。图像与文档继续预览，主页文档不再包含会截获点击的翻页 / 打开按钮。

- 动作库去除“全部分类”，分类标签作为连续完整列表的定位入口；点击跳转，滚动跟踪高亮并将当前标签滚入可见区域。前八类顺序为基础、流程控制、变量、文本处理、计算、系统、文件、应用；搜索仍按名称、类别和类型 ID 匹配。
- README 与 Wiki 同步更新。按用户要求不连接或测试真机。
