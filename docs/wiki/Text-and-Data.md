# 文本、列表、字典与编码

## 文本输入与处理

“文本”输出填写内容；“要求输入”在运行时弹出对话框，可配置标题、占位提示、默认值，并选择文本、数字或日期时间输入。用户输入成为独立输出，取消会取消流程。

| 操作 | 常用配置 / 行为 |
| --- | --- |
| 追加文本 | 选择追加目标与新增内容，输出连接后的文本 |
| 替换文本 | 原文本、查找内容、替换内容，可忽略大小写 |
| 正则替换 | 正则、替换内容、大小写选项；可开启替换捕获组 |
| 匹配文本 | 输出匹配结果，适合继续接列表操作 |
| 更改大小写 | 大写或小写 |
| 修剪首尾空白 | 去掉两端空白 |
| 拆分文本 | 按指定分隔符生成列表 |
| 拼接文本 | 接收列表，按换行、空格、逗号、无分隔符或自定义分隔符拼接 |
| 计数 | 按项目、字符、词、句子或行计数 |
| 注释 | 写流程说明，不解析变量模板，不产生输出 |

正则使用 RE2/J，不支持前后查找和正则反向引用等 RE2 不支持的语法。替换模板里的捕获组替换与正则反向引用是两件事，可用相关开关启用替换捕获组。正则输入最多 16 Ki 字符，模式最多 1024 字符。

## 列表

“列表”用项目行编辑，每项可以是常量或完整变量引用。列表最多 256 项。可选择首项、末项、随机项、指定第几项或连续范围；索引从 **1** 开始，范围包含两端。

“从列表中选取”运行时显示选择界面，支持单选和多选；单选输出该项，多选输出列表。排序支持文本 / 数字以及升序 / 降序；另有倒序和项目计数。“重复处理每一项”可逐项处理结果。

列表不会自动当作一个数字参与计算。需要多个数一起处理时，使用统计、遍历，或先选出具体项。

## 字典

“字典”在一个操作中维护多组键 / 值，不必每个键单独创建操作。值支持自动、文本、数字、布尔类型，自动类型可直接引用现有列表或字典。

- 获取字典值：指定字典和键，输出对应值。
- 设置字典值：指定键及新值，输出修改后的字典；需要后续复用时引用该输出。
- 获取所有键：输出键名列表，可继续遍历。

字典最多 256 个键值对，容器最多嵌套 16 层。把字典写入工作文件后再读取，可恢复原类型；把它嵌入普通文本则只得到文本表示。

## 从输入中提取内容

| 操作 | 输出 |
| --- | --- |
| 从输入中获取文本 | 文本；支持容器及可读取文本文件的内容 |
| 从输入中获取数字 | 数字列表；支持正负数、小数、科学计数法、全角数字和 `1,234.56` |
| 从输入中获取 URL | URL 文本列表，支持 HTTP(S) 及可识别的自定义协议 |
| 从输入中获取图像 | 可解码的本地图像 / 授权 URI 列表 |
| 从输入中获取文件 | 文件路径 / 授权 URI 列表 |

数字的小数点使用 `.`。图像提取不会自动下载网页图像，也不执行 OCR。文件与图像引用仍须有实际读取权限。

## 编码与哈希

Base64 编码支持文本、图像、文件，预设不换行、每 64 或每 76 字符换行。解码输出 UTF-8 文本，不能把任意二进制 Base64 解码后直接当成图像文件。URL 编解码用于文本和参数，不执行网页请求。

“获取哈希”可对文本 UTF-8 字节、文件或图像原始字节计算摘要，输出小写十六进制。算法包括：MD5、SHA-1、SHA-224 / 256 / 384 / 512、SHA3-224 / 256 / 384 / 512、BLAKE2b-512、BLAKE2s-256、RIPEMD-160、SM3、CRC32，共 15 种。

## 日期、日程与设备数据

“当前日期与时间”输出格式化文本，默认日期部分跟随地区，简体中文常见默认值为 `yyyy-MM-dd HH:mm:ss`。可自定义格式及系统 / 指定时区；例如 `yyyy/MM/dd` 只保留日期，`HH:mm` 只保留时分。

“格式化日期”把可识别的日期输入转换为指定格式；参数选择可用日期预设和时区弹框。创建日程支持标题、开始 / 结束、说明、地点、日历与提前提醒；读取日程按指定日期及时区输出日程字典列表，通过系统实例查询处理重复、跨天和全天事件。

“获取当前电池电量”输出不带 `%` 的 0–100 整数。“获取当前位置”输出经纬度等字典和独立属性变量，需要位置权限及系统定位可用。
