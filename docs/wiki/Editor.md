# 编辑器

## 添加和整理操作

编辑器是独立的全屏界面，底部内容延伸至透明手势导航区域，不再按小白条高度额外上推；键盘弹出时仍会避让，三键导航保留可点击区域保护。动作库始终按完整列表连续显示：前八类依次为基础、流程控制、变量、文本处理、计算、系统、文件、应用，其余分类接在后面。点击分类标签会跳到对应分类的位置，不会隐藏其他类别；上下滚动时标签自动高亮当前所在分类，必要时横向滚动显示该标签，不再提供“全部分类”。搜索仍按操作名称、类别名称和类型 ID 匹配，连续展示匹配项。点击操作添加，也可以从动作库长按拖动，放到两个操作之间或分支内部。

已添加操作可以通过左上角拖动手柄移动。靠近页面边缘会滚动，候选插入位置会出现间隙。拖动如果、菜单、重复等结构时，会带着内部操作一起移动。

每个操作提供向上、向下、复制、删除图标，长按显示说明。不适用的按钮使用禁用色。拖到标题栏红色 X 与点击操作删除按钮使用相同删除行为：移除控制结构会一并移除其中全部操作。

## 参数和变量

点击“添加动作”时，操作面板从底部滑入并渐显，关闭时收起；长按拖入操作时立即让出编辑区域，保留拖放定位方式。

输入框既可输入常量，也可插入变量胶囊。点击胶囊可以替换来源、定位原操作或移除；键盘退格可删除完整胶囊。“选择魔法变量”让你直接在当前编辑器选择可用操作输出。

有输出操作可打开“加入到变量栏”，让后续操作输入时更容易选到它。变量类操作始终在栏内，共享输入及输入提取类默认开启。无输出操作不提供可引用结果，具体规则见 [变量](Variables.md)。

变量栏开关、输出存入变量和“将此操作添加为变量”位于每张操作卡片的“更多”，默认折叠；点开后按钮文字变为“更少”，再次点按收回后恢复“更多”。“显示结果”的“支持取消”也在这里。输入与操作本身的设置始终可见，底部上移、下移、复制、删除四个图标不折叠。新增 / 设置 / 获取 / 添加到变量这四类操作不显示“将此操作添加为变量”，也没有“更多”。折叠状态不改变已保存的变量或取消设置。

## 平板与折叠屏

在可用宽度至少 600 dp 的大屏窗口中，动作库常驻编辑器侧面：平板约占窗口宽度的 1/3，折叠屏约占 1/2。设置 → 外观可选择左 / 右，默认左侧；仅大屏设备显示该设置，偏好保存在本机，不写入快捷指令 XML。

折叠屏通过 Jetpack WindowManager 的折叠信息及硬件特征识别；系统报告竖向分隔铰链时，两个区域避开铰链。封面屏、分屏后不足 600 dp 的窄窗口使用手机底部面板。横屏主页导航位于左侧，编辑器动作库的位置仍由用户选择。不同厂商的折叠信息及特殊姿态存在差异，本次尚无平板 / 折叠屏实机验证。

## 撤销、重做与保存

- 标题栏弯箭头分别撤销、重做编辑；导出和这两个按钮均支持长按提示。
- 参数、顺序和结构更改会进入编辑历史；撤销后继续编辑会形成新的历史分支，旧重做记录随之失效。
- 编辑器保留草稿以支持恢复。完成将当前内容提交到快捷指令库；导出与保存是不同操作。
- 新建流程没有操作时，点击完成直接关闭，不创建空条目。
- 新建默认名称按当前语言生成不重名后缀，例如“新快捷指令”“新快捷指令1”“新快捷指令2”；同时打开的编辑器也预留名称。已有名称和恢复的草稿不自动改名。
- 已有流程删掉所有操作后点击完成，会删除该快捷指令及其完成结果；放弃修改则保留原来的已保存流程。

## 运行、定位错误和取消

编辑器的播放按钮运行当前内容；运行时变为终止按钮。点击终止会取消当前运行及其子调用、等待和待处理交互。已完成的通知、文件写入等副作用不会撤销。

运行时可查看当前执行位置和输出。修改或删除相关操作后，旧结果会清除，避免把历史数据误当成新结果。失效的变量引用使用错误色提示：需要改选仍然存在、且在当前作用域可用的输出。

“快速查看”和“显示结果”只有执行到该步骤时才弹出；它们不产生自己的魔法变量。显示结果默认仅有确定按钮，开启支持取消后，取消会终止运行，确定则继续。

输出结果、显示结果和快速查看支持图像、文档及混合列表，具体格式与预览限制见 [图像与文档](Images-and-PDF.md)。

编辑操作时先确认结构末尾的“结束如果”“结束菜单”“结束重复”，再决定新操作应放进分支还是接在整个结构后面。
