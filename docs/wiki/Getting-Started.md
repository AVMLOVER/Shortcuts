# 快速上手

## 安装与首次启动

从项目 [Releases](https://github.com/AVMLOVER/Shortcuts/releases) 下载 APK。日常更新应使用相同发布签名的 Release 覆盖安装，以保留数据。Debug 与 Release 通常签名不同，不能相互覆盖。

首次启动会引导申请通知、忽略电池优化及上层显示等权限。后续可在设置按实际使用场景授权；文本、数字和字典等本地处理不要求 Root 或 Shizuku。

## 第一条快捷指令

1. 在快捷指令主页点击右下角 `+`，进入编辑器并填写名称。
2. 打开“添加动作”，在基础类别选择“文本”，填入 `你好，Shortcuts！`。
3. 在它后面添加“快速查看”。内容保持上一步结果，或通过魔法变量直接选择刚才的文本输出。
4. 点击播放，会在执行到快速查看时预览内容；关闭预览后流程继续。
5. 点击完成保存。主页会显示该快捷指令及操作数量，点击播放即可运行。

“显示结果”可自定义对话框标题与内容；“快速查看”适合查看文本、图像或文件。主页结果框显示小号“输出结果”标题，可共享文本、图像或文件，不必每条流程都添加预览操作。点击框内共享按钮之外的任意位置会隐藏整个框；切换页面或返回前台不会重新出现，下一次运行会显示新的结果。主页文档是静态预览；翻页和外部打开可使用“快速查看”或“显示结果”。

新建默认名会避开当前库中及其他编辑窗口正在使用的名称：简体中文下依次为“新快捷指令”“新快捷指令1”“新快捷指令2”……。可以自行改名；已有快捷指令和恢复的草稿不会批量改名。

## 组织主页

- 点击标题栏搜索按钮，在标题栏内输入名称，列表实时过滤。
- 点击文件夹按钮新建文件夹，配置名称、图标和颜色。
- 每条快捷指令的文件夹按钮打开半屏分类界面；汉堡菜单可切换文件夹，返回键优先关闭侧栏。
- 快捷指令的复制按钮生成独立副本，名称追加 `Copy`。
- 图标可长按查看说明；红色 X 用于删除。

## 使用示例文件

从主页右上角导入按钮或“设置 → 数据 → 导入”选择 XML。项目 [examples](https://github.com/AVMLOVER/Shortcuts/tree/main/examples) 中的 `hello.xml`、`dictionary-calculation.xml`、`list-input-files.xml`、`share-number-statistics.xml` 是快捷指令示例；`settings.xml` 是设置格式示例，不能当作快捷指令导入。

导入会新建副本，不覆盖已有快捷指令。包含本地文件 URI 的流程，换设备后可能需要重新选择文件。
