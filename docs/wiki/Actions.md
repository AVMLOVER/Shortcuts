# 操作参考

当前动作库共 **110 个操作**。下表名称对应简体中文界面，类型 ID 是 XML 中稳定的 `action.type`。参数里的变量会在运行时解析；详细输入、输出与限制见各专题。

无独立输出的交互 / 系统动作不提供魔法变量，不能把它们当成新的数据来源。控制结构的结果与作用域见 [流程控制](Control-Flow.md)。

## 配置与扩展

有输出的操作通常可选择加入变量栏。变量类操作始终显示，共享输入及输入提取默认开启；其他有输出操作默认关闭。列表 / 字典支持多行编辑，网络操作有查询参数、请求头和请求体字段，Intent 可配置有类型 extra。

XML 示例与应用版本迁移见 [文件与 XML](Files-and-XML.md)；平台权限与后端能力见 [权限与模式](Permissions-and-Modes.md)。
