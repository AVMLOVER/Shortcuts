# 常见问题与排查

## 为什么提示“该值无法用于数字运算”？

通常传入了列表、布尔值、字典或不可解析的文字。检查上一步输出及变量类型；“添加到变量”会形成列表，更新单个数应使用计算后“设置变量”。“从输入中获取数字”输出也是列表，需取项或统计。

## 为什么魔法变量变红或选不到？

引用操作可能已经删除、被移动到不可用分支、尚未执行或没有输出。重新选择当前作用域内的有效来源。复制流程会维护内部引用，手工改 XML 操作 ID 时则要同时维护引用。

## 为什么变量栏没有某个输出？

对有输出操作打开“加入到变量栏”。变量类操作始终显示；共享输入和输入提取默认显示。关闭固定不妨碍在合法位置手动选择魔法变量。快速查看、通知、共享等无输出动作没有独立输出变量。

## 为什么分享菜单里没有 Shortcuts 或我的流程？

先保存包含启用“从共享表单获取内容”的流程，且其父结构也须启用。内容类型要与本次分享匹配。草稿不会发布分享目标，系统直接分享目标还受缓存、数量和排序影响；可先找到 Shortcuts 入口再选择流程。

## 为什么子流程找不到 / 改名后会怎样？

预设调用使用 UUID，改名不影响。删除目标、单独导入调用者而未导入目标，可能导致缺失；重新选择已保存目标。合集导入会重映射同批内部预设调用，合集外引用不会自动修复。

## 为什么返回后原流程继续，结束也一样？

返回与结束只结束当前被调用流程。返回交还指定值，结束交还空文本，然后调用者继续。要取消整次执行，点击运行中的终止按钮。

## 为什么删空快捷指令后主页没有它？

完成时不保存空流程。已有流程删光操作后点击完成会移除该条目，这是预期行为；不想提交这次修改时选择放弃。

## 为什么 XML 提示需要更高版本？

文件的 `appVersion` 大于当前支持版本。更新应用后重试，不要仅删除版本字段来强行运行可能不兼容的操作。旧文件缺少版本时应用会自动迁移。

## 能否直接导入 Apple 快捷指令？

目前支持本项目的单项 / 合集 XML，不支持 Apple `.shortcut` 文件或 iCloud 链接，也未覆盖所有 Apple 专用及第三方 App 私有动作。

## 为什么压缩 80% 后体积没有变成原来的 80%？

该值是 JPEG / WebP 编码质量，体积还受画面、原编码和尺寸影响。需要明显减小体积时先调整图像尺寸，再压缩并检查实际大小。

## 为什么 PDF / APK / 图像换设备后失效？

XML 不包含文件本体和系统 URI 授权。重新选择文件或 PDF 保存目录，并迁移实际需要的工作文件。PDF 未设目录会打开系统保存窗口。

## 为什么自动化没有按时执行？

先确认规则启用、目标可手动运行、监视通知存在，再检查通知、后台 / 自启动、忽略电池优化及定位 / Wi-Fi 权限。时间条件按分钟匹配，系统休眠可能错过该分钟。强制停止后需要重新打开应用。

## 为什么 Shizuku / Root 模式仍然报权限错误？

设置保存的是模式，不是授权。服务可能未启动或已重启，Root 管理器可能未授权，设备策略也可能拒绝相应命令。系统目录文件操作目前要求 Root，Shizuku 不等于拥有所有目录权限。

## 有哪些容量限制？

| 项目 | 上限 / 规则 |
| --- | --- |
| 单条流程配置 | 1000 个操作，结构嵌套 16 层 |
| 执行 | 普通执行共享 5000 步；条件性重复内部及其子调用另共享最多 1 亿步，最多 16 层调用，拒绝循环调用 |
| 条件性重复 | 最多 100000 次，同时受条件性重复内部共享步数约束 |
| 指定次数重复 / 逐项重复 | 最多 1000 次 / 列表容量，同时受执行预算约束 |
| 列表 / 字典 | 256 项 / 键，容器嵌套 16 层 |
| 单步值 | 262144 字符；部分缓存有额外总量限制 |
| XML | 单项 1 MiB；合集 8 MiB / 1000 项 |
| 自动化 | 100 条规则，等待队列最多 16 个触发 |
| 系统分享输入 | 最多 16 文件；单文件 32 MiB，总计 64 MiB |
| 图像合成 | 单张 1600 万像素、输出边长 16384，另受堆内存预算约束 |
| PDF | 100 页、32 MiB |
| 获取应用列表 | 每批最多 256 项，可设置起始偏移 |

不同操作还可能有更严格的输入限制；可分批、逐项或缩小内容后再处理。

## 闪退后怎样反馈？

“设置 → 日志”可查看及导出崩溃日志，界面也显示日志目录。正常运行和已处理错误不持续写 trace；未捕获异常会记录版本、设备、线程、步骤及堆栈，文件按数量保留。系统直接杀进程或部分原生崩溃不一定能进入该处理器。

提交 [Issue](https://github.com/AVMLOVER/Shortcuts/issues) 时附应用版本、Android / 系统版本、运行模式和最小复现步骤。XML、API 参数和日志可能含个人数据，分享前先检查并移除敏感内容。
