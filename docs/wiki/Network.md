# 网络、URL 与 HTML

## 获取 URL 内容

提供 **GET、POST、PUT、PATCH、DELETE**。方法可预设、每次询问或由变量提供，变量解析后也只接受这五种方法。URL、查询参数和请求头值支持变量。

查询参数以键 / 值行编辑，由客户端编码。请求头最多 50 项，名称不区分大小写，不允许重复或换行；连接分帧相关字段由客户端管理。

POST、PUT、PATCH 可选择请求体：

| 类型 | 使用方式 |
| --- | --- |
| JSON | 填写原始 JSON 或完整字典 / 列表变量；上方留空时序列化下方键值字段 |
| 表单 | 按 UTF-8 `application/x-www-form-urlencoded` 编码键值 |
| 文件 | 发送选择的文件原始字节，默认 `application/octet-stream`，可改 Content-Type |
| 文本 | UTF-8 原文，可改 Content-Type |

GET 和 DELETE 不发送请求体。JSON 字段支持自动、文本、数字、布尔类型；自动类型可以保留变量中的字典或列表。

响应按 Content-Type 中的 charset 解码，默认 UTF-8，输出**文本**；不会自动把响应 JSON 转成字典，也不会自动将响应下载为图像文件。非 2xx 状态报错，204 / 205 输出空文本。

连接和读取超时各为 15 秒，响应读取上限 1 MiB，流程单步结果仍受 262144 字符上限约束。请求体可受 32 MiB 及文件后端限制。手动终止运行会取消 HTTP 工作并断开连接。

## 示例：调用 JSON API

在“获取 URL 内容”中设置目标 API、方法 POST、请求体 JSON，然后添加字段：

| 键 | 类型 | 值 |
| --- | --- | --- |
| `query` | 文本 | 选择输入文本的魔法变量 |
| `limit` | 数字 | `10` |
| `enabled` | 布尔 | `true` |

需要身份验证时按接口要求加请求头，例如 `Authorization`。XML 导出包含操作参数，发布前应移除令牌等私密值。接快速查看可以先检查原始响应文本。

## 扩展 URL 与响应头

“扩展 URL”跟随 HTTP 重定向，输出最终地址。“获取 URL 头部”输出响应头字典，键为小写；一个头部有多个值时输出列表，否则输出文本，可接字典及列表操作。

两者先用 HEAD；终点返回 405 / 501 时改用 GET 取头部，不读取正文。最多检查 8 个地址，支持相对 Location，循环或无效地址会报错。跨源重定向不转发 Authorization、Cookie 和 Proxy-Authorization。

## URL 组件与提取

“获取 URL 组件”不发网络请求，可提取方案、用户名、密码、主机、端口、路径、查询、片段，或全部组件。全部输出字典：

`scheme`、`user`、`password`、`host`、`port`、`path`、`query`、`fragment`。

端口存在时为数字，其余为文本，不存在的部分为空文本，查询保留百分号编码。支持自定义应用协议。

“从输入中获取 URL”从文本、容器或可读取文本文件提取链接并输出列表。要打开其中一条，先取列表项，再接“打开 URL”；它不会自动批量打开所有结果。

## HTML

“获取 HTML”从地址获取源代码文本，支持查询参数。“查看 HTML”接收 HTML 文本，在非全屏窗口预览静态效果；它不是完整浏览器，不能据此预期交互网页或复杂脚本正常运行。

HTTP 与 HTTPS 均可由用户指定，HTTPS 使用系统证书校验。网络动作的实际结果还受网络、服务器、证书和接口权限影响。
