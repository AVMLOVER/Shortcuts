# 桌面小组件与快捷设置

## 桌面小组件

从桌面启动器的小组件入口选择 Shortcuts，提供四种布局：

| 标称尺寸 | 最多快捷指令 |
| --- | --- |
| 1×1 | 1 |
| 2×2 | 2 |
| 4×2 | 4 |
| 4×4 | 8 |

进入配置后选择已保存快捷指令，可以少于容量；完全不选时不创建组件。尺寸由启动器解释，实际占格和留白会随桌面应用变化。

有上层显示权限时，点击组件直接启动前台服务，不经过本应用 Activity；组件继续显示圆形运行状态。要求输入、菜单、列表选择和显示结果可在桌面 M3E 浮层交互。系统授权、文件选择或打开其他应用等仍受 Android 前台规则限制。

## 顶部结果浮层

授予“在其他应用上层显示”后，组件运行结果可显示在屏幕上方。未授权时只进入应用的权限提示页面，不执行该快捷指令；授权后回桌面再次点击运行。结果保留图像、文档和列表类型，显示实际图像、可翻页 PDF、文本文件内容或可打开的文档卡片；显示结果对话框也支持这些内容，详情见 [图像与文档预览](Images-and-PDF.md)。

普通文字结果约 7 秒后关闭；包含图像 / 文件引用的结果会保留到点击关闭或再次运行，方便查看及翻页。运行中的输入、菜单和结果确认继续等待用户操作。主进程和服务结束或系统收回权限时，浮层会随之结束。

小组件按实际执行到的操作避免重复输出：只要执行过“显示结果”，或成功发送过通知 / 提醒，就使用这些操作自身的展示，不在完成后再加一层结果。未走到的分支、禁用的显示步骤不影响结果选择；发送失败仍会报告错误。

如果没有上述展示，小组件会在流程完成后显示最后一次“快速查看”的原始内容；没有快速查看时显示正常输出。小组件中的快速查看先记录内容，不逐次弹出以免与后面的显示结果重复。错误仍会展示；用户取消显示结果后不再重复显示“运行停止”。这些规则仅用于小组件，编辑器和主页保留原行为。

组件配置保存的是本机快捷指令 ID，不随流程 XML 导出。删除快捷指令后，应按需要重新配置桌面入口。

## 系统快捷设置磁贴

在快捷指令卡片点击“加入控制中心”图标，选择绑定 4 个磁贴槽位之一。

- Android 13 及以上：应用向系统请求添加磁贴，由用户确认。
- 较旧系统：在系统快捷设置的编辑界面手动加入对应 Shortcuts 磁贴。
- 点击磁贴会在解锁后进入运行界面，运行绑定的快捷指令。

一个槽位绑定一条流程，重新绑定会更新该槽位。删除流程会清理对应绑定。这里的“控制中心”对应 Android 系统快捷设置，不要求安装额外控制面板。
