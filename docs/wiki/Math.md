# 计算与数字处理

## 数字、计算和表达式

“数字”可以输入数值或选择完整变量引用，输出数字类型。“计算”提供运算选项和左右值；“计算表达式”可在一个表达式中组合变量、函数、括号、常量及运算符。

Android 数学路径使用 Rust 核心，经 JNI 调用。十进制结果按 34 位有效数字处理；三角函数和开方使用浮点近似，输出会整理尾数，但不承诺任意精度的三角计算。

| 能力 | 写法 |
| --- | --- |
| 四则与乘方 | `+ - * / ^` |
| 余数 / 非负模 | 表达式 `%` / `mod(a,b)` |
| 最大公约数 / 最小公倍数 | `gcd(a,b)` / `lcm(a,b)`，参数需为整数 |
| 绝对值、最小、最大 | `abs(x)`、`min(a,b)`、`max(a,b)` |
| 三角与反三角 | `sin`、`cos`、`tan`、`asin`、`acos`、`atan` |
| 平方根、立方根、多次方根 | `sqrt(x)`、`cbrt(x)`、`root(x,n)` |
| 取整 | `round(x,digits)`、`ceil(x,digits)`、`floor(x,digits)` |
| 常量 | `pi`、`e` |

示例：`sin(30)`、`sqrt(81)`、`root(32,5)`、`gcd(18,24)`、`mod(-1,5)`、`round(12.345,2)`。表达式中的函数名使用上表英文标识；可通过编辑器变量选择插入数值。

普通“计算”的 `%` 是百分比运算：左值 `200`、右值 `11` 得到 `22`。表达式 `200 % 11` 是取余，得到 `2`。负数的非负模应使用 `mod`。

## 角度单位

在“设置 → 计算”选择：

| 单位 | 一周 |
| --- | --- |
| 角度（默认） | 360° |
| 弧度 | `2*pi` |
| 百分度 | 400 grad |

设置同时作用于普通计算与表达式中的三角函数；反三角函数也按该单位输出。`sin(30)` 得到 `0.5` 的前提是角度模式，弧度模式应使用 `sin(pi/6)`。

## 数字取整与格式化

“数字取整”独立操作和计算里的取整都支持四舍五入、向上、向下。位数为 `0` 表示整数，`2` 表示两位小数，`-2` 表示百位，允许范围 −100 至 100。向上表示向正无穷，向下表示向负无穷：`ceil(-1.2)=-1`，`floor(-1.2)=-2`。

“格式化数字”输出**文本**，支持 0–20 位小数、千位分隔及 BCP 47 地区标签。需要继续计算时建议保留原数字，把格式化放在展示之前；例如带地区分组符的结果可能无法直接作为数字输入。

## 统计

输入 1–256 项数字列表，或用逗号、分号、空白分隔的数字文本。可计算总和、平均、最小、最大、中位数、众数、极差、总体方差、总体标准差和数量。众数输出所有并列众数的升序列表，其他结果按对应数值输出。

## 因数与质数

“因数”可选质因数、全部正因子或是否质数。

| 输入与选项 | 结果 |
| --- | --- |
| `6`，质因数 | 文本列表 `2`、`3` |
| `6`，全部正因子 | 文本列表 `1`、`2`、`3`、`6` |
| `8`，质因数，次方形式 | 文本列表 `2^3` |
| `7`，是否质数 | 布尔值 `true` |

支持无符号 64 位整数；分解要求正整数。`1` 的质因数列表为空，正因子是 `1`。分解有计算步数限制，因子超过列表 256 项上限时报错。

## 常见失败

- 数字列表直接进入单值计算：先取项、统计或遍历。
- 使用添加到变量更新计数：值变成列表，应计算后设置变量。
- 除以零、函数定义域不满足、无穷结果或超限：流程报错。
- 表达式留空：需先填写表达式，没有默认 `1+2`。

界面显示用的格式化与数学数值应分别处理，尽量在最后一步再加单位、千位分隔符等文字。
