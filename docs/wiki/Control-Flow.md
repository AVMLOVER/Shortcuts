# 流程控制

## 如果与否则

如果包含比较对象、条件及比较值。对象和比较值都可使用变量；空值判断等一元条件不需要比较值。满足时执行“如果”分支，不满足时执行“否则”；不需要否则可以移除。两条分支结束后继续执行“结束如果”后面的内容。

| 条件 | 规则 |
| --- | --- |
| 等于 / 不等于 | 两边均为数字时按数值比较，否则按文本比较 |
| 包含 / 不包含 | 文本包含关系 |
| 大于 / 小于 / 大于等于 / 小于等于 | 两边需能用于数字运算 |
| 为空 / 不为空 | 判断文本表示是否为空 |
| 为真 | 判断布尔真值的表示 `true` |
| 匹配 | RE2 正则匹配，找到匹配片段即满足 |
| 来源于系统共享 / 其他快捷指令 | 仅关联入口内容的比较对象可选，见 [调用与返回](Shortcut-Calls.md) |

## 菜单

“从菜单中选择”显示标题及项目。用户点选后，只执行对应菜单项内部操作，然后继续“结束菜单”后的公共操作。`menu_choice` 保存所选项目名称。取消选择会取消运行。

菜单分支和结束菜单有明确标记。将公共步骤放在结束菜单后，避免在每个项目中重复编写。

## 三种重复

| 操作 | 运行方式 | 输出 |
| --- | --- | --- |
| 重复 | 按指定次数运行内部操作 | 最后一次的数据流结果 |
| 重复处理每一项 | 遍历列表，当前项为 `repeat_item`，序号为 `repeat_index` | 最后一次的数据流结果 |
| 条件性重复 | 至少执行一次，在结束重复处比较条件，满足才退出 | 最后一轮结果，另提供 `repeatCount` |

条件性重复复用如果的普通条件，包括大于、小于、包含、匹配等；输入来源专用条件不属于循环结束条件。结束处可选本轮操作的输出及变量。

例如：新建数字变量 `计数=0`，循环内计算 `计数+1` 并设置回 `计数`，结束处设“计数 大于等于 3”，则执行三轮。不能用添加到变量更新计数，否则值会成为列表。

单个循环最多 1000 次，并受整次运行 5000 步预算限制；多层循环或子流程会共同消耗该预算。条件始终不满足时会在达到限制后报错，不能作为无限后台循环使用。

## 返回、结束和手动终止

| 方式 | 当前流程 | 调用者 |
| --- | --- | --- |
| 返回 | 立即停止后续操作，返回指定内容 | 以返回内容继续 |
| 结束快捷指令 | 立即停止，结果为空文本 | 以空文本继续 |
| 自然运行到末尾 | 正常完成 | 以最后结果继续 |
| 运行按钮变为终止后点击 | 取消整条运行链 | 一并取消 |
| 停止快捷指令（兼容操作） | 结束当前流程并保留指定值 | 按结果继续 |

手动终止不是回滚。已经执行的通知、写文件、安装和外部应用动作不会撤销。

## 等待与等待返回

“等待”支持秒 / 毫秒、输入和加减调整。“等待返回”用于打开应用 / URL / Intent 后，回到 Shortcuts 时继续。它依据离开和返回事件工作，不检查其他应用中的任务是否完成；进程被结束后也不会恢复等待。
