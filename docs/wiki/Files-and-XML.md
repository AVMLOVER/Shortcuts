# 文件、XML 与备份

## 三种文件访问入口

| 入口 | 适用方式 |
| --- | --- |
| 软件工作目录 | 文件系列操作的默认位置，使用自定义文件夹名和相对文件名 |
| 系统文件选择器 | 选择文件或保存 PDF，使用系统授权 URI |
| 自定义系统目录 | 文件操作开启外部路径，运行时需要 Root 并检查授权 |

工作目录为 `getExternalFilesDir(null)/workspace`，外部存储不可用时回退内部目录。常见路径是 `/storage/emulated/0/Android/data/com.germanium.shortcuts/files/workspace/`，实际值可在设置的数据区域查看。

默认工作目录拒绝 `..`、绝对路径和逃逸根目录的符号链接。外部路径写入 / 删除会请求确认；Shizuku 模式不替代此处要求的 Root。

## 文件操作

创建文件夹、创建文件、读取、写入、追加、列出文件、删除文件、获取文件信息和获取文件元数据可按用途组合。

“选择文件”调用 Android 原生选择器，选择后尝试读取，文本内容可直接传给下一步。“获取文件信息”主要输出文件**内容**，适合把存储的字典或列表接回数据操作；查询名称、大小等属性使用“获取文件元数据”。

文件内容支持文本，也可保留列表、字典、数字和布尔类型。文本按 UTF-8 保存，有类型内容使用应用的 XML 值格式；再次读取会恢复类型。追加文件按内容规则追加，不等于给命名变量做加法。

普通文本文件读取最多 1 MiB；工作流单步值仍受 262144 字符限制。图像和部分二进制接口另有大小上限，不能据此认为所有二进制文件都可作为普通文本读取。

## 快捷指令 XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<shortcut version="1"
    id="b1b8e02b-a8d8-4c48-a19b-4e146f438ad8"
    uuid="b1b8e02b-a8d8-4c48-a19b-4e146f438ad8"
    appVersion="10004"
    createdAt="1793100000000" updatedAt="1793100000000"
    icon="layers" color="#6750A4">
  <name>你好</name>
  <steps>
    <action id="text-1" type="text" enabled="true">
      <parameter key="value">你好，Shortcuts！</parameter>
    </action>
    <action id="preview-1" type="quick_look" enabled="true">
      <parameter key="value">{{@text-1}}</parameter>
    </action>
  </steps>
</shortcut>
```

- `version` 是结构版本：无分支通常为 1，有嵌套分支为 2。
- `appVersion` 是要求的应用版本码，与结构版本独立，当前为 `10004`。
- `id` 对应仓库文件名，`uuid` 用于跨流程调用识别。
- `createdAt/updatedAt` 为 Unix 毫秒，修改时间不能早于创建时间。
- 操作顺序由 XML 决定；操作 ID 在整个快捷指令内唯一，参数以字符串保存。
- 变量胶囊序列化为 `{{name}}`、`{{@操作ID}}` 及属性引用。

旧文件缺少 UUID 时从原 ID 得到稳定 UUID，缺少或使用旧应用版本时自动补齐并原子升级。原 ID、操作、时间和变量引用保留；再次读取当前文件不重复重写。要求更高应用版本时拒绝打开 / 导入，并显示需要的版本码，不覆盖原文档。当前应用版本码为 10004，读取旧版 10003 等文档会保留 UUID、操作、参数和时间戳，只升级应用版本元数据。

## 导入与导出

单条快捷指令可在界面导出；设置的“导出全部快捷指令”生成 `<shortcuts version="1">` 合集。主页右上角和设置均可导入单项 / 合集。

导入为每项分配新的 ID / UUID，不覆盖同 ID 条目；合集内部的预设子流程目标会重映射，同批以外的引用保持原样。操作 ID 和流程内部输出引用保留。空流程会跳过，全空导入报错。

| 会导出 | 不会随快捷指令导出 |
| --- | --- |
| 已保存操作、参数、名称、图标、颜色、UUID | 自动化规则、工作文件、图像 / APK 本体、草稿、运行变量和结果 |
| 合集中保存的多条流程配置 | 文件夹元数据、桌面小组件 / 磁贴绑定、外部文件 / 目录授权 |

文件夹不随导入自动创建，外来的文件夹引用会清空。跨设备后请重新选择 APK、文件及 PDF 保存目录，并检查合集外的子流程引用。

## 容量与备份

单项 XML 最多 8 MiB；合集最多 32 MiB / 1000 项。DTD、实体、未知结构版本、重复键等会被拒绝。自动化规则独立保存在 `files/automations/`，设置在 `files/settings.xml`，草稿在 `files/drafts/`，快捷指令在 `files/shortcuts/`。

XML 导出是流程备份，不是完整应用备份。迁移前先导出流程，再单独保留需要的工作文件；卸载应用可能删除应用专属目录中的内容。不要为切换 Debug / Release 签名而直接卸载唯一数据副本。

## ZIP 压缩与解压

制作 ZIP 接受文件或文件列表，最多 256 个条目，源文件总计和输出归档各最多 32 MiB。输出保存在自定义工作文件夹，文件名须以 `.zip` 结束。

解压 ZIP 接受单个 ZIP，最多 256 个条目（包括目录），总展开内容最多 32 MiB。输出到指定文件夹内新建的唯一子目录，返回文件路径列表；拒绝路径穿越、绝对路径、重复名称和文件 / 目录冲突，不覆盖已有工作文件。文件大小格式化接收字节数字，可选 1024 或 1000 进制。

单条快捷指令最多 10000 个操作；这一限制与合集最多 1000 条快捷指令、列表最多 256 项分别计算。
