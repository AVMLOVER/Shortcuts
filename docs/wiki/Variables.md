# 变量与数据类型

## 三种取值方式

| 方式 | 含义 | XML 中的写法 |
| --- | --- | --- |
| 上一步结果 | 当前传给操作的输入值 | `{{input}}` |
| 命名变量 | 当前流程作用域中保存的值 | `{{数量}}` |
| 魔法变量 | 某个已完成操作的输出 | `{{@操作ID}}` |

界面用可点击胶囊呈现这些引用，通常不需要手写模板。XML 引用使用稳定操作 ID，操作的显示名称不是引用身份。

## 数据类型

应用支持文本、数字、布尔值、列表、字典和空值。JSON 的 `null` 保留为空值，显示为空文本，转回 JSON 时仍为 `null`；写入有类型工作文件也可保留。图像及文件操作通常传递可读取的路径或 URI，交给对应平台操作处理。

完整参数只有一个变量时保留原类型。例如整个输入为 `{{数量}}` 时可以保留数字；输入为 `共 {{数量}} 个` 时生成文本。列表也一样：完整引用保留列表，嵌入文本后会按文本形式展开。

数字运算接受数字或可解析的数字文本。把一个多项列表当成单个数使用，会报“该值无法用于数字运算”。应先选取列表项、计算统计数据，或检查是否误用“添加到变量”。

## 四个变量操作

| 操作 | 用途 | 示例 |
| --- | --- | --- |
| 增加变量 | 创建一个尚不存在的变量；同名已存在时报错 | 新建 `总额 = 0` |
| 设置变量 | 替换值；变量不存在时也可设置 | 把 `总额` 替换为本轮计算结果 |
| 获取变量 | 选择命名变量或魔法变量并输出它 | 重新取得先前保存的字典 |
| 添加到变量 | 将原值和新增值收集为有序列表；列表按项追加 | 原值 `2` 再添加 `3`，得到 `[2, 3]` |

累加金额、更新计数器应先计算，再**设置变量**。添加到变量用于收集多个结果，不执行加法，也不把两段文本直接粘在一起；文本连接使用“追加文本”或“拼接文本”。

命名变量以字母或下划线开头，可包含字母、数字和下划线，最长 64 字符；`input` 为保留名称。变量在本次运行内存在，不会自动持久化；跨运行保留数据请写入文件。

## 变量栏与魔法变量

变量类操作始终加入变量栏，没有单独开关。其他有输出操作可用“加入到变量栏”固定结果，默认关闭；“从共享表单获取内容”和六种“从输入中获取…”操作默认开启。

关闭固定只影响输入工具栏的快捷展示，不影响通过魔法变量手动选取合法输出。只有当前作用域和执行顺序允许的操作才可选；未执行的分支不能提供有效结果。

注释、通知、共享、等待、快速查看、显示结果、打开应用、返回、结束等无输出操作不提供自己的输出变量。它们执行时可能保留原数据流，但不会生成一个新的可引用结果。

## 独立属性变量

| 操作 | 可独立选择的属性 |
| --- | --- |
| 获取图像信息 | `width`、`height`、`mimeType`、`size`、`name`、`path` |
| 获取当前位置 | `latitude`、`longitude`、`accuracy`、`altitude`、`timestamp`、`provider` |
| 条件性重复 | `repeatCount`，主输出仍是最后一轮结果 |

XML 形式如 `{{@location.latitude}}`、`{{@loop.repeatCount}}`。重复处理每一项时可使用 `repeat_item` 和从 1 开始的 `repeat_index`；嵌套循环结束后恢复外层上下文。

## 输入来源

“从共享表单获取内容”读取的是本次流程的原始入口输入，不受前面操作改变上一步结果的影响。入口可能是 Android 系统分享，也可能是另一条快捷指令调用。

相关来源信息会沿命名变量、魔法变量和别名链传递。“如果”比较对象关联这些输入时，才显示“来源于系统共享 / 来源于其他快捷指令”。手工输入的无关常量不提供这两项；直接启动且没有入口输入时，两项都不匹配。
