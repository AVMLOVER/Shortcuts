# 示例工作流

下面示例可在编辑器逐项搭建。文中的“选择某步输出”表示使用界面的魔法变量，无需手写操作 ID。先保存再配置共享入口、子流程调用或自动化。

## 1. 输入数量，计算金额

| 顺序 | 操作 | 参数 |
| --- | --- | --- |
| 1 | 要求输入 | 标题“购买数量”，提示“请输入数量”，输入类型数字 |
| 2 | 计算 | 左值第 1 步输出，乘 `12.5` |
| 3 | 格式化数字 | 来源第 2 步输出，小数位 2 |
| 4 | 显示结果 | 标题“合计”，内容为格式化输出 |

需要继续运算时选第 2 步数字结果；第 3 步是用于显示的文本。

## 2. 条件性重复到 3

1. 增加变量：名称 `计数`，类型数字，值 `0`。
2. 添加条件性重复。
3. 循环内部添加计算：`计数 + 1`。
4. 循环内部添加设置变量：名称 `计数`，值选本轮计算结果。
5. 结束重复处设：对象 `计数`、条件“大于等于”、比较值 `3`。
6. 循环后快速查看，选择条件性重复的主输出，结果为 `3`。

在魔法变量中还能单独选择该循环的重复次数，这里也是 `3`。第 4 步必须是设置变量，添加到变量会生成列表。

## 3. 字典保存并读取

1. 字典添加多个键，例如 `name` 为文本、`quantity` 为数字、`enabled` 为布尔。
2. 写入文件：文件夹 `Documents`、名称 `config.xml`、内容完整引用字典输出。
3. 读取文件：使用相同文件夹和文件名。
4. 获取字典值：字典来源选读取输出，键为 `quantity`。
5. 计算或快速查看。

不要先把字典放进一个带说明句子的文本框再写入，那样保存的是说明文本而非字典类型。

## 4. 从系统分享文本中提取数字

1. 从共享表单获取内容，内容类型文本。
2. 从输入中获取数字，来源选择共享输入输出。
3. 计算统计数据，统计项选择总和，来源为数字提取输出。
4. 快速查看或共享。

保存后，在其他应用选择文本，例如 `午餐 25，交通 8，饮料 6`，分享至 Shortcuts 并选择该流程，结果为 `39`。

## 5. 分享图像并纵向拼接

从共享表单获取内容（图像）→ 从输入中获取图像 → 拼接图像（纵向、间隔 16、统一尺寸）→ 快速查看 → 共享。

需要运行时决定拼接方式，可开启“运行时预览并调整”。图像数量和合成像素受限制，失败时先减小尺寸或数量。

## 6. 文本转 PDF

文本（填入标题和正文）→ 制作 PDF（文本、A4、字号 12、边距 36）→ 共享。

在制作 PDF 中预设默认目录即可直接保存；未设置时运行会弹出系统保存窗口。共享内容选择 PDF 输出 URI。

## 7. 调用可复用流程

按 [快捷指令调用与返回](Shortcut-Calls.md) 的“翻倍”示例创建子流程。调用者先输入数字，再运行其他快捷指令并把数字传入，最后使用调用输出。

需要让一个流程兼顾系统分享与子调用，可将“如果”的对象设为共享输入，按信息来源选择不同分支。

## 8. 电量低时通知

先创建流程：获取当前电池电量 → 通知（标题“电量提醒”，内容插入电量输出）。保存后新增自动化，条件“电量低于”，阈值 `20`，选择该流程。

检查通知、忽略电池优化和后台设置。该规则在状态进入低电量时触发，不会持续每 15 秒发送一次。

## 9. URL 响应头检查

文本（目标 HTTPS 地址）→ 获取 URL 头部 → 获取字典值（键 `content-type`）→ 快速查看。

部分头部值为列表，多值时可接取列表项或拼接文本。请求失败或对应键不存在时，应检查服务器实际响应。
