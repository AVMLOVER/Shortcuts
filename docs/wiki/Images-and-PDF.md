# 图像与 PDF

## 获取图像

可以选择系统文件 / 图像、调用系统相机拍照、接收其他应用分享，或从前面的输入提取图像。图像操作接受可读取的路径、已授权 `content://` URI，部分操作接受图像列表或共享内容。

获取图像不会自动抓取网页图像。文件 URI 必须有读取授权，跨设备导入 XML 后通常需要重新选择。系统相机、媒体访问和截图按场景请求相应授权。

## 图像操作及参数

| 操作 | 主要参数与输出 |
| --- | --- |
| 获取图像信息 | 宽、高、MIME 类型、字节大小、名称、路径；每项可独立选作魔法变量 |
| 裁剪图像 | 左上角 `x/y`、像素宽高，输出 PNG |
| 蒙版图像 | 椭圆、圆形、圆角、矩形或自定义图像；Alpha / 亮度蒙版，可反转 |
| 叠放图像 | 底图、叠图、缩放、透明度、旋转、相对中心的像素偏移 |
| 翻转图像 | 水平、垂直或双向 |
| 拼接图像 | 横向、纵向、网格；间隔、列数、统一尺寸选项 |
| 调整图像 | 宽高像素、保持比例；一边填 0 时自动计算该边 |
| 压缩图像 | JPEG / WebP、质量百分比，支持滑条和输入 |
| 用文本制作图像 | 文本、宽度、字号、边距、对齐、文字 / 背景颜色、透明背景，输出 PNG |

蒙版、叠放、翻转、拼接、调整尺寸、压缩提供“运行时预览并调整”。默认按预置参数执行，开启后显示 M3E 预览对话框，可调整后确定，取消会停止流程。像素裁剪和文本图像使用其参数执行。

## 参数细节

- 蒙版圆角半径范围 0–50%；自定义蒙版可由第二张输入或单独变量提供。
- 叠图缩放为底图宽度的 1–400%，透明度 0–100%，旋转 −360–360 度；偏移相对中心，单位像素。
- 拼接接受 1–16 张图像，间隔 0–1024 像素、网格列数 1–16，空白透明。
- 保持比例且两边均给出时，调整尺寸会等比例适配边界，不强行拉伸。
- 压缩百分比是**编码质量**，不是目标体积比例。80% 不表示文件一定缩小到原来的 80%；JPEG 会把透明区域填白，扩展名应与格式对应。
- 普通合成输出为工作目录中的 PNG，相对路径可继续引用；文件名留空时自动生成。

图像合成会处理 EXIF 方向；单张输入 / 输出最多 1600 万像素、输出边长最多 16384，同时按可用堆内存检查总合成预算。超限请先缩小图像或减少一次处理数量。

## 快速查看图像

将图像操作的输出直接传入“快速查看”，会显示图像本身，不显示文件路径。支持工作目录文件、已授权的 `content://` URI、图像列表以及共享表单的图像内容；根据实际内容识别，不要求文件必须带图像扩展名。多张图像可以滚动查看，文本等其他输入继续显示文字。预览采用缩小采样并处理 EXIF 方向，不改变原图；桌面小组件也使用相同预览。

## 输出、对话框和文档预览

“输出结果”和“显示结果”也使用相同预览。将图像、文件或列表的魔法变量作为内容框的完整值，类型会保留；如果在变量前后拼接说明文字，则按文本展示。主页结果、编辑器结果和小组件桌面浮层均支持图像与文档。

- PDF 使用系统渲染器一次显示一页，提供上一页 / 下一页；加密、损坏或系统无法渲染的 PDF 可尝试使用其他应用打开。
- 1 MiB 以内的 UTF-8 文本文件显示内容，最多显示 65536 字符；其他格式显示文件名、MIME 类型和字节数，以及“打开文档”按钮。Office 文档需要本机安装支持的查看器，不在应用内实现 Office 排版。
- 文件预览输入限 32 MiB，图像和 PDF 按预览尺寸缩小采样，原文件保持不变。
- 点击“打开文档”只授予查看器临时读取权。文件被移除、URI 授权失效或没有兼容应用时会显示错误。

## 图像和文档通知

发送通知和发送提醒可直接接受上述变量。通知使用系统 [BigPictureStyle](https://developer.android.com/reference/android/app/Notification.BigPictureStyle) 展示前 4 项中的首个可预览图像或 PDF 页面；文字摘要最多列出前 16 项，点按通知后可查看完整输入。图像标题 / 摘要中的文件引用显示文件名，文档也可从通知打开预览。

通知入口保留的是内容及文件引用，不复制原图或原文档。被删除的文件和失效授权无法继续打开；应用缓存被系统清理后，旧通知的预览入口也可能失效。最多保留 32 条操作通知和 64 份临时预览载荷，避免无限积累；通知折叠与展开的外观由系统决定。

## 截图

“获取截图”每次通过系统 MediaProjection 授权，保存 PNG 到公共 `Pictures/Screenshots`，通常对应 `/sdcard/Pictures/Screenshots`。输出为媒体 URI，可接快速查看或其他图像操作。

截图是系统屏幕捕获，需要用户确认；受保护内容可能无法捕获。它与普通工作目录中的图像文件保存位置不同。

## 制作 PDF

“制作 PDF”接收文本、图像或混合输入；输入模式可选自动、文本、图像。页面可选 A4 / Letter，字号和页边距单位为点。文本自动分页，图像逐张居中适配页面。

1. 在编辑器设置默认保存目录，由系统目录选择窗口授权。
2. 设置文件名和页面参数，运行时将结果保存到目录。
3. 没有默认目录或授权已失效时，系统打开“保存文件”窗口，让用户选择位置。
4. 输出保存后的 `content://` URI，可继续读取或共享。

最多 100 页、32 MiB；为控制内存，图像页可能缩小采样。默认目录保存的是系统目录授权，不是随意写入任意绝对路径的权限，导入到其他设备后需要重新授权。

## 示例

从其他应用分享多张图像 → 从共享表单获取内容 → 从输入中获取图像 → 拼接图像（纵向，间隔 16）→ 快速查看 → 共享。

或：文本 → 用文本制作图像（透明背景）→ 叠放图像（使用另一张图像作底图）→ 快速查看。

## 旋转、转换与二维码

旋转图像支持 −360–360 度，透明扩展画布；转换图像支持 PNG / JPEG / WebP，JPEG 的透明区域填白，质量范围 0–100。两者均可按参数直接执行或开启运行时预览并调整，沿用原有像素和内存预算。

生成二维码使用 ZXing，输出 PNG，支持 128–2048 像素边长、L/M/Q/H 纠错等级及 UTF-8 文本。内容超过所选等级容量会报错。“从图像读取条码”识别单张图像中的二维码及支持的常见条码，输出一条识别文本，不会自动打开链接。需要从相机读取时，可先接系统拍照操作。

## 过滤图像与 PDF 页图像

“过滤图像”对输入文件 / 图像列表按宽度、高度、文件名、MIME 类型、字节大小或方向筛选，不是给图像添加视觉滤镜。支持相等、不等、大小比较及包含、开头、结尾；数值属性比较数字，文字比较忽略大小写。方向值使用 `portrait`、`landscape` 或 `square`。可按名称、宽、高、大小排序，反转顺序并限制输出数量（1–256），结果仍是图像路径列表。不能识别为图像的文件跳过。

“从 PDF 页制作图像”接收一个 PDF，页码使用 `all` 或 `1,3-5`，从 1 开始，按填写顺序去重；最多 100 页。按设定宽度保持页面比例，白色背景输出 PNG 列表，放入自定义目录下的新建批次子目录。单张仍受 1600 万像素 / 可用内存限制，批次 PNG 总大小最多 32 MiB；失败或取消会清理本批次已生成文件。

## 图像文字识别（OCR）

“从图像中提取文本”接受图像或图像列表，输出识别文字，多张用换行连接。使用随 APK 打包的 [ML Kit 文字识别模型](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)，提供中文与拉丁字母、日语与拉丁字母、拉丁字母三种选择；英文、德文等使用拉丁模型。识别在设备上完成，不上传图像，也不在运行时下载模型。

图像会按 EXIF 方向处理并适配 2048×2048 边界；清晰度、排版和文字类型影响识别质量，不保证每个字符正确。输出最多 262144 字符。

## GIF、帧与视频

| 操作 | 输入与输出 |
| --- | --- |
| 制作 GIF | 图像列表、已有 GIF 或视频，输出新 GIF |
| 为 GIF 添加帧 | 一份原 GIF 加额外图像 / 帧输入，输出新 GIF，原文件保留 |
| 从图像中获取帧 | GIF / 视频 / 静态图像，输出有序 PNG 路径列表；静态图像输出一帧 |
| 从 GIF 制作视频 | 一份 GIF，经系统 H.264 编码器输出 MP4，无音轨 |

GIF 制作可设置宽高（16–1024 像素）、新增帧间隔（10–60000 ms）、循环次数（0 表示无限）及最大帧数（1–120）。画布面积还会按设备堆内存限制，内存不足时报错，请降低宽高。图像等比适配画布，空白和透明区域填白；GIF 调色板最多 256 色，重新编码可能改变颜色或体积。已有 GIF 的帧间隔会保留，新增普通图像使用设定间隔；复制动画帧由 Glide 解码并合成处置效果。追加后的总帧数也受上限约束，不会悄悄丢弃原 GIF 后半段。

视频输入从开头每 100 ms 抽取一帧，最多取设置的帧数，不代表保留整段长视频。GIF 转 MP4 最多 120 帧、输入按最长边 1280 像素采样并调整为偶数尺寸，保留解码后的逐帧显示时长。设备必须提供可用的 H.264 / YUV420 编码器，失败会报错；本操作不调用外部应用。

输入文件和输出文件上限为 32 MiB；帧提取批次 PNG 总计也为 32 MiB，失败会清理本批次文件。逐帧处理以减少内存；不支持 Live Photo 的苹果专有组合格式。结果可接快速查看、文件操作或系统共享。

## GIF 与多信息文本预览

快速查看、显示结果、主页输出框及小组件预览均支持多信息文本，按格式排版；将多信息文本写入文件后，直接预览该文件也会恢复格式，不展示内部 XML。保存的列表、字典等有类型工作文件按解码后的内容展示。普通 UTF-8 文本显示文件正文，PDF 显示页面，其他文档保留文件卡片与外部打开入口。

Android 9（API 28）及以上可动态播放有效 GIF，最多 120 帧、单帧最多 400 万像素，并按最长边 1200 像素采样；旧系统或超出动态预览限制时显示首帧。系统通知使用静态图片样式，只显示 GIF 首帧。预览不会修改 GIF 文件。
