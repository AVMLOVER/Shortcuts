# 设备操作与 Root

## 电源控制

关机和重启仅接受 Root 模式，并在执行时通过 `su` 再次检查实际 UID 为 0。标准或 Shizuku 模式、授权失败都会报“本操作无权运行”。这些操作没有独立输出变量。

重启目标可选系统、Recovery、Bootloader、Download、EDL。命令目标来自固定白名单，是否可用取决于设备固件；不支持时不会自动切换目标。

## 写入分区

此操作仅支持 Root 和原始 `.img` 镜像。输入可以是选择的文件 URI、工作目录路径或变量；目标须明确填写完整块设备路径，例如 `/dev/block/by-name/boot_a`。选择文件及运行时都按实际文件名校验扩展名（不区分大小写），`.zip`、`.bin`、`.img.zip` 等一律拒绝。

运行会校验实际 Root 授权，解析目标真实路径、检查它是块设备、取得容量，并把镜像暂存到应用私有缓存以确定完整大小。镜像为空或超过分区容量时拒绝；Android sparse 格式须先转为 raw `.img`。缓存空间不足也会拒绝。

执行前显示高危确认，列出源文件、用户指定目标、实际块设备、镜像字节数和分区容量。确认后才执行写入，写入前再次检查目标和容量。取消确认不会写入。临时镜像在结束时清理，原源文件不变。

写入不可撤销，错误镜像或分区可能导致数据丢失、无法启动或设备损坏；请先备份并核对。写入中不要断电或中止。中断、超时或失败可能已经产生部分写入，不提供自动回滚。该操作的默认写入超时为 10 分钟。应用不会自动判断镜像是否适配机型或替你备份分区。

**项目真机回归不执行分区写入，也不执行关机或各重启目标。** 参数与命令生成仅做不接触块设备的校验。

## 媒体音量与手电筒

获取媒体音量输出 0–100 的整数，设置媒体音量接受相同比例；系统音量档位会量化实际结果。操作的是媒体通道，标准模式即可使用。

手电筒提供开 / 关，使用系统 CameraManager，按需申请相机权限。无闪光灯或相机被占用时会报错；不要求 Root。

## 朗读文本

使用系统 TTS 引擎，可设置语言标签、语速 0.1–3、音高 0.1–2。空语言跟随系统，语言数据须由系统引擎提供。动作等待朗读完成，长文本分段，取消会停止并释放引擎。不需要录音权限，也不提供新的输出变量。
