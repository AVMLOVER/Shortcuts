# 1.0.2 Re-Release

应用版本仍为 `1.0.2`，versionCode 仍为 `10002`，沿用原发布签名覆盖安装。

- 主页每条快捷指令增加复制图标，长按显示提示。副本名称追加 ` Copy`，保留外观、文件夹、参数、停用状态与全部分支；新建独立的快捷指令及操作 ID，并重写流程内的魔法变量引用。原快捷指令不变。
- 变量操作始终加入变量栏，移除对应开关；其他有输出的操作仍可自行开关。获取变量直接选择现有命名变量、上一操作结果，或在编辑器内选择魔法变量。
- 操作库显式提供“设置变量”：用新值替换原值，保留自动类型。原有“添加到变量”继续保留旧内容并追加到有序列表。“增加变量”用于创建一个尚不存在的名称。
- 列表参与数字运算或大小比较时，错误会说明列表与数字的区别，并提示用设置变量更新数值。例如从 111 开始每轮除以 3，使用设置变量更新计数器，5 次后小于 1；使用添加到变量会得到 `[111, 37]`，不能作为数字比较。旧 XML 不会自动改变追加的语义。
- 已有操作支持跨流程层级移动：可放在如果、菜单、重复的前后，也可进入分支末尾；整组移动保留全部子操作与引用，禁止移入自身或后代。插入空隙按操作头部、整组结束位置、分支末尾显示，拖动时边缘滚动加快。
- 拖到红色 X 和点击操作底部“移除”走同一个删除入口，删除整个操作及所有嵌套内容。移除来源后，保留在其他操作中的变量引用立即显示为错误色，点击后可替换或删除；键盘仍按整颗变量删除。
- 新增文案覆盖简体中文、英语、德语、日语、繁体中文。
- 编辑器导出旁提供撤销、重做弯箭头；三者长按显示提示。撤销覆盖增删、整组移动、参数、名称和外观；同一字段连续输入合并成一次，最多保留 100 个快照。撤销后产生新修改会清空重做分支，切换新编辑器时重新开始历史；恢复操作会清掉旧运行结果并保存当前草稿。
- 获取 URL 内容支持 GET、POST、PUT、PATCH、DELETE，以及运行时询问或从变量指定方法；支持查询参数、请求头、JSON/表单/文件/文本请求体。新增扩展 URL、获取 URL 头部、获取 URL 组件；已有从输入中获取 URL 可提取多个链接，输出列表。实现与边界见 [网络操作](NETWORK.md)。

变量语义参考 [Apple 快捷指令变量说明](https://support.apple.com/en-mide/guide/shortcuts/apdd2b316022/ios)。当前验证范围与 APK 校验见 [验证记录](VERIFICATION.md)。
