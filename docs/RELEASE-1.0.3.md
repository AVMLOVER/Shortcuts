# 1.0.3

- 基础类操作排在动作库最前面，编辑器标题简化为“编辑”。
- 新增运行其他快捷指令：预设目标或运行时选择，按 UUID 查找，改名不影响调用；找不到目标则报错并停止。输入支持文本与有类型变量，被调用流程的共享输入操作可读取这个输入。
- 新增返回：立即退出当前流程，将指定结果交还调用处，作为运行其他快捷指令的输出继续执行。没有显式返回时，调用处接收子流程最后结果。子流程变量与调用者隔离，执行模式沿用当前模式；普通执行共享 5000 步预算，条件性重复内部及其子调用另共享最多 1 亿步（单个条件性重复最多 100000 次），最多 16 层调用，循环调用报错。
- 新增结束快捷指令：终止当前流程，不返回内容；在子流程中使用时，调用者收到空文本后继续。编辑器和主页的播放图标在运行时变成终止图标，点击取消整条调用链及待处理交互。网络取消会断开当前 HTTP 连接。
- 如果的比较对象引用共享输入相关输出时，条件中增加来源于系统共享、来源于其他快捷指令；命名变量、魔法变量及别名链会保留来源信息。普通文字或无关变量不显示这两项。直接运行且没有共享/调用输入时，两种来源条件均不满足。
- 编辑器上移、下移、复制、移除改为图标，长按提示；移除使用主题错误色，禁用项目使用禁用色。
- 新增获取应用列表，输出包名、应用名称或两者组成的文本列表，可包含系统应用。每批最多 256 项，通过起始位置取得后续批次。设置增加应用列表访问入口及日程读写授权入口。
- 简体中文、英语、德语、日语、繁体中文资源同步更新。

## XML 升级

结构版本 `version=1/2` 保留。每个快捷指令增加 `uuid` 和 `appVersion=10003`。旧文件没有 UUID 时，从原 ID 得出稳定 UUID；文件名、ID、创建和更新时间、操作 ID、变量引用及参数不变。仓库打开旧文档时使用原子替换升级；再次读取无需重写。

新建、复制、导入各产生独立 UUID。合集导入会重写合集内预设调用的目标 UUID；指向合集外的引用保持不变。导入不会覆盖原文档。

`appVersion` 大于当前版本时拒绝打开、导入或覆盖，并显示文件要求的版本号。文件内容保持原样。调用目标如果删除，会在执行调用时重新检查并报错。

应用列表访问采用 Android 包可见性机制与已声明的 QUERY_ALL_PACKAGES；该权限不属于定位一类的标准运行时弹窗，设置入口打开系统/厂商应用权限页面。参见 [Android 官方说明](https://developer.android.com/training/package-visibility/declaring)。
