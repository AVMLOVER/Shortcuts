# Shortcuts 1.0.5

应用版本 / versionCode / XML appVersion 分别为 1.0.5 / 10005 / 10005。旧文件按现有原子迁移机制升级，保留 UUID、操作、参数和时间；更高版本文件继续拒绝打开。

本版新增 13 个操作，动作库共 142 个：四种多信息文本与 HTML / Markdown 互转、多信息文本转图像、过滤图像、PDF 页转图像、图像 OCR、制作 GIF、GIF 转视频、追加 GIF 帧、提取帧、重命名文件。截图中已有的转换图像、图像信息和输入图像操作继续复用。

富文本作为独立有类型值传递和保存；图像及视频逐页 / 逐帧处理，并提供输出容量、页数、帧数及取消清理。重命名输出新路径，拒绝无权限、目标已存在和非法名称。

README、操作参考及 Wiki 源文件同步。已在小米 API 37 设备完成 11 项功能 / 预览检查及备份、保留数据核对，17 个原有文件与原偏好项保留；没有执行关机、重启或分区写入。验证范围见 [记录](VERIFICATION-1.0.5.md)。
