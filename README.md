## 0.7 更新

- 全应用开关统一使用 Material 3 开关的 thumbContent：开启为对勾，关闭为 X，包括操作选项、自动化、应用过滤和小组件配置。底栏再缩短至最大 360dp，保持同步过渡；选项和预设颜色跟随 Material 配色，自定义 RGB 保留。
- 如果、菜单、重复显示明确的结束标记；删除或编辑操作后清除所属流程的完成结果，首页不再残留旧输出。主页完成卡片只显示结果。
- “显示结果”：自定义标题/内容，默认只有确定；打开“支持取消”后，取消或返回会停止流程，确定继续。快速查看、通知、等待、打开应用等无输出操作不提供输出变量和魔法变量。“增加变量”等变量操作移除冗余的输出存入变量栏。
- 计算核心改为 Rust，JNI 接入 Android，包含 arm64-v8a、armeabi-v7a、x86_64、x86。十进制计算按 34 位有效数字处理；三角函数默认使用角度，可在设置选择弧度或百分度，数值通过有限的 f64 计算。支持六个三角函数、abs/sqrt/round/min/max、gcd/lcm/mod；表达式默认为空。普通计算的 % 是左值乘以右值百分比，表达式的 % 仍取余，mod 为非负模。
- 普通计算输入数字或完整魔法变量；追加文本可选择追加目标。等待、振动可输入或用 +/- 调整，支持秒/毫秒和振动强度。
- 文件可无损写入字典、列表及标量，再用“获取文件信息”或读取文件输出原类型；文件元数据改为独立操作。增加原生选择文件、图片选择、系统相机、像素裁剪和图片信息；宽、高、类型、大小、名称、路径可分别选作魔法变量。
- Base64 可编码文本、图片和文件，选择不换行、每 64/76 字符换行。新增有种子的确定性 UUID、已保存快捷指令数量。获取 URL/HTML 可加查询参数，查看 HTML 使用非全屏静态预览。
- 应用选择显示图标，默认隐藏系统应用，开关可显示；Intent 目标可选择已安装软件，填写包名及组件。首页运行/导出/控制中心/文件夹/删除改为图标，长按可看提示，删除和放弃为主题错误色。
- Shell 默认从工作目录执行，先 pwd/ls 预览；可能写入、删除或无法确定的命令需确认，所有模式拒绝根目录批量删除和裸设备写入。标准/Root 实时读取管道，Shizuku 轮询动态输出。自定义系统目录文件操作需 Root，写入/删除前确认。
- 文件夹支持创建、预设图标与自定义颜色；首页和侧栏列出文件夹，单条快捷指令可从半屏列表归类。新增 NFC 卡片录入/触发与指定 Wi-Fi 连接条件，受 Android 的派发、定位及网络访问权限约束。
- 原生桌面小组件：1×1 单个、2×2 两个、4×2 四个、4×4 八个快捷指令；允许少于容量，未选中不能完成添加。运行状态圈在桌面宿主中旋转；顶部结果浮层需要上层显示权限，否则进入应用的运行界面。交互性动作仍需回到应用确认。
- 操作库支持长按发起系统拖拽，拖入编辑器可选择操作前后或分支末尾；原有拖动手柄排序保留。

新增接口、权限和文件格式详见 [动作说明](docs/ACTIONS.md)、[XML 格式](docs/XML_FORMAT.md)。测试范围见 [验证记录](docs/VERIFICATION.md)，不可将仅接入接口的能力视为所有厂商设备均已验证。

## 现有功能

- 独立全屏 EditorActivity，进入/返回动画、草稿恢复、当前动作标记、保存/运行/停止。首页加号仅显示图标，快捷指令名称上方显示操作总数（包含停用动作和所有分支）。
- 110 个可添加操作，按功能分类并可搜索：基础、变量、文本、计算、字典、列表、流程控制、文件、日期、应用、系统、网络、编码、设备、图像。
- 变量操作：增加新变量、设置变量（替换）、获取变量、添加到现有变量（追加为有序列表）。变量类操作始终加入变量栏，获取变量可直接选择命名变量或魔法变量。每个操作的输出可直接引用，也可在操作下方点击“将此操作增加为变量”，默认引用该操作的输出。
- 要求输入：自定义标题、浅色占位提示和默认内容；支持文本/数字/日期时间。自动生成独立输出变量。字典用可增删的键/值表格，列表用项目行。
- 列表支持首项、末项、随机、第几项（从 1 开始）、范围、交互选择/多选、计数、排序、倒序；“重复处理每一项”提供 `repeat_item` 和 `repeat_index`。
- 普通计算及计算表达式；可插入变量、操作输出、符号和函数。条件、可删除的否则分支、菜单分支、重复、停止均可嵌套。运行前解析流程，执行栈调度分支。
- 快速查看是独立操作，执行到它时显示其指定内容。没有快速查看时不自动弹窗；编辑器仍显示运行记录，也可手动查看末尾结果。
- 打开软件先查询系统启动器应用列表，再选择应用。另有自定义 Intent、APK 文件选择与安装：标准模式走系统安装器，Root/Shizuku 走 `pm install`，实际权限在执行时检查。
- 文本/正则替换、匹配、大小写、修剪、计数、拆分与合并；日期格式化、随机数、UUID、Base64、URL 编解码、文本摘要、HTTPS GET、剪贴板、设备信息。
- 在软件文件目录内自定义文件夹，创建、读取、写入、追加、列出、删除文件和获取文件信息。
- 创建系统日程（CalendarContract，可带提醒）、自定义标题/内容通知；发送提醒用 `Shortcuts` 作为通知标题。
- 自动化页面可新增、编辑、启用/停用和删除规则；条件选择快捷指令自动运行。支持时间、电量低于、电源接入/断开、Wi-Fi/网络连接、屏幕开启/关闭、开机。前台服务持续监视，可从常驻通知暂停。
- 首次启动请求通知权限和忽略电池优化；设置提供授权入口和应用自启动/后台设置入口。主题默认跟随系统，可选亮/暗。
- 单项/合集 XML 导入导出、跟踪日志与崩溃日志。简体中文、英语、德语、日语、繁体中文分别存放在资源文件中。

图标是手工绘制的同类叠层渐变 Android 自适应矢量图，包含单色主题图标。

## 快速体验

1. 点击加号，按分类添加操作。输入参数时，底部可插入前面的变量和操作输出。
2. 设置内导入 `examples/list-input-files.xml`，运行后选择列表项目、输入数量、计算金额、写入软件目录，再快速查看文件内容。
3. 文件参数的“文件夹名”默认为 `Documents`。设置可查看实际根目录，通常为 `/storage/emulated/0/Android/data/com.germanium.shortcuts/files/workspace/`。
4. 创建并保存快捷指令后，到自动化选择条件和该快捷指令。授权通知及后台运行，确认常驻监视通知存在。
5. 设置内选择标准 / Root / Shizuku；后两者需要设备已提供并授权相应服务。模式选择本身不授予权限。

## 数据与执行边界

- `files/shortcuts/<id>.xml`、`files/settings.xml`、`files/automations/<id>.xml`；编辑草稿为 `files/drafts/<id>.xml`。单文件原子替换。旧 v1 快捷指令和旧变量/计算动作兼容；分支工作流使用 XML v2。导入生成新快捷指令 ID，不覆盖同 ID 的本地数据。
- 工作文件位于 `externalFilesDir/workspace`，存储不可用时回退内部目录。只允许根目录内的相对路径，拒绝 `..`、绝对路径和逃逸目录的符号链接。文本为 UTF-8，文本文件最多 1 MiB；截图 PNG 最多 32 MiB，作为单步输出读取时还受 256 Ki 字符上限约束。删除仅删除指定文件。
- 每次运行的变量独立；流程最多 1000 个配置操作、16 层嵌套，实际执行上限 5000 步。命名变量总文本 4 Mi 字符，操作输出缓存 8 Mi 字符，历史记录约 2 Mi 字符/1000 条；超限报错或裁剪历史。
- 自动化按条件从不满足变为满足时触发，同一时间规则每日去重；规则状态持久化，编辑/停用不会被旧监视状态覆盖。多条流程排队执行，最多等待 16 个触发。启动监视时已经满足的状态条件可以触发一次。
- 时间条件为监视服务的分钟匹配，15 秒检查一次；没有精确闹钟、唤醒锁或漏跑补偿，休眠可能推迟或错过该分钟。没有承诺秒级、准点闹钟或永不被系统结束。
- 开机后尝试恢复已启用且未暂停的监视。用户强制停止、系统/OEM 后台限制可阻止启动；需在系统提供的自启动/后台权限页允许。应用不能替用户授予这些权限。
- 后台流程遇到输入、列表选择、快速查看、系统授权、打开应用等交互，会发送返回软件继续的通知；同一次运行等待用户操作，不重放此前的通知/写文件/安装等副作用。通知不可用时交互会明确失败。进程被结束后不恢复正在执行的流程。
- APK 引用是文件选择器授予的 URI。跨设备导入 XML 后通常需要重新选择 APK；Shizuku 安装以其实际 shell/root 身份执行，设备策略仍可能拒绝。
- 正则采用 RE2/J，避免回溯导致卡死；不支持前后查找和正则反向引用等 RE2 不支持的语法。替换捕获组可开启；正则输入限制 16 Ki 字符。

苹果快捷指令的操作还包括第三方 App 提供的动作及 Apple 专用服务。本版实现以上核心操作和 Android 对应能力；尚未接入照片、联系人、地图导航、媒体处理、智能家居、健康和第三方私有接口，也不兼容导入 Apple `.shortcut` 文件。支持清单和来源见 [动作说明](docs/ACTIONS.md)。

## 构建和验证

使用 JDK 17、Android SDK 37、NDK 30.0.16248370 和 Rust（本轮 1.99.1）。Android Studio 打开本目录，配置自己的 `local.properties`（`sdk.dir`）。

```powershell
.\gradlew.bat :core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

macOS / Linux 先 `chmod +x gradlew`，再使用 `./gradlew`。APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。首次构建需访问 Maven 和 crates.io。先通过 rustup 安装 aarch64-linux-android、armv7-linux-androideabi、x86_64-linux-android、i686-linux-android 四个目标。cargo 需在 PATH，或通过 CARGO_HOME 指定目录；Gradle 自动运行 tools/build-native.ps1 或 build-native.sh，按 Cargo.lock 构建四种原生库。

Material 3 固定为 `1.5.0-beta01` 的 `MaterialExpressiveTheme`，仍是预发布依赖；其他 Compose 依赖由 BOM 固定。源码包不包含构建产物、缓存、`local.properties` 或签名私钥。

验证结果与 APK SHA-256 见 [验证记录](docs/VERIFICATION.md)，数据格式见 [XML 规范](docs/XML_FORMAT.md)。1.0.2 使用同签名覆盖升级和独立测试包验证，先备份数据并记录指纹，测试仅清理专用样例。实际测试数、结果和范围以验证记录为准。真机测试说明见 [测试说明](docs/TESTING.md)。

## 模块

`core`：有类型值、变量与操作输出、表达式、安全文本处理、预解析流程和执行栈、XML 仓库、工作文件、自动化规则及触发判断、子进程。

`app`：Compose 界面、独立编辑器 Activity、应用列表、跨 Activity 交互协调、应用级执行队列、Android 日程/通知/安装接口、Root/Shizuku 后端、前台自动化服务、权限与日志。


0.7 补充：添加动作文字使用统一图标宽度对齐；获取当前位置输出经纬度字典及单独魔法变量，设置提供位置权限入口。计算设置提供角度、弧度、百分度，默认为角度，普通计算和 Rust 表达式三角函数同时生效。

最新补充：标题栏内实时搜索、拖拽插入空隙、三角函数尾数整理、sqrt/cbrt/root、普通计算和独立数字取整操作（方向与位数可配置）。角度单位三个选项统一尺寸；日志仅写崩溃记录。

“当前日期与时间”输出可读文本，提供自定义格式与时区，默认日期部分遵循语言地区，简中为 yyyy-MM-dd HH:mm:ss。拖拽实现维持用户已手动确认正常的版本。
