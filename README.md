# Shortcuts

**用可视化操作连接日常任务，让文本、数据、图像和 Android 系统能力协同工作。**

[下载 APK](https://github.com/AVMLOVER/Shortcuts/releases) · [使用手册](docs/wiki/Home.md) · [问题反馈](https://github.com/AVMLOVER/Shortcuts/issues) · [自动构建](https://github.com/AVMLOVER/Shortcuts/actions/workflows/android.yml)

Shortcuts 是一款受 Apple 快捷指令启发的 Android 原生工作流应用。你可以把多个操作按顺序连接，传递变量，通过条件、菜单和重复组织逻辑，再从应用首页、系统分享、桌面小组件、快捷设置磁贴或自动化规则启动。

界面使用 **Jetpack Compose + Material 3 Expressive**，计算核心使用 **Rust**，快捷指令及主要配置保存在可导入、可导出的 **XML** 中。普通操作可在标准模式下使用，特权任务可按需选择 Shizuku 或 Root。

## 特色功能

### 可视化编辑，流程结构清楚

- 独立全屏编辑器，按类别搜索和添加操作，基础操作优先展示。
- 从操作库长按拖入指定位置；已添加操作可拖动排序，插入位置显示空隙提示，靠近边缘时滚动页面。
- 如果、菜单、重复使用嵌套结构和明确的结束标记，方便区分分支内外的操作。
- 上移、下移、复制、删除和撤销 / 重做；图标按钮支持长按提示。
- 拖到标题栏 X 或使用删除按钮可移除操作；删除控制结构会一并删除其内部操作。
- 草稿恢复、运行状态、错误位置与运行结果查看。运行时播放按钮切换为终止按钮，可取消整条调用链。
- 完成时不保存空流程；已有快捷指令删空后完成，会移除该快捷指令。

### 魔法变量与有类型的数据

操作之间可以传递文本、数字、布尔值、列表和字典。文本框中的变量显示为带橘色 `x` 标识的可点击胶囊，可以替换来源、定位操作，按退格键整块删除。

- **增加变量**：创建新的命名变量。
- **设置变量**：替换变量内容，也可在尚不存在时设置它。
- **获取变量**：选择现有命名变量或魔法变量。
- **添加到变量**：把内容追加为有序列表，适合收集多次结果。
- **加入到变量栏**：将操作输出固定到后续操作的输入工具栏；变量类操作始终显示，共享输入和输入提取操作默认开启。
- 图像信息、位置和条件性重复提供独立属性变量，如宽高、经纬度、重复次数。

完整的变量引用保留数据类型；把变量嵌入句子时则生成文本。因此，字典和列表可以直接参与后续操作，也可以保留类型写入文件。

### 快捷指令可以互相调用

“运行其他快捷指令”支持预设目标或每次运行时选择，并向子流程传入文本、数字、列表或字典。子流程通过“从共享表单获取内容”读取入口输入，使用“返回”把结果交还调用处，随后由原流程继续执行。

目标按 UUID 识别，改名不影响调用；目标缺失时报错并终止。各次调用的命名变量独立，“如果”还可判断相关输入来自系统分享还是其他快捷指令。

### 共享输入与共享结果

保存包含已启用“从共享表单获取内容”的快捷指令后，可以从其他应用分享文本、链接、图像或文件到 Shortcuts，再选择适用的流程。输入提取操作可从中获取文本、图像、URL、文件和数字。

结果卡片及独立“共享”操作均可打开 Android 系统分享菜单。配合“等待返回”，可以跳转到其他应用，返回 Shortcuts 后继续执行后面的操作。

### 原生外观与个性化

- Material 3 Expressive 主题、悬浮底栏、分组设置和可展开内容。
- 跟随系统 / 亮 / 暗主题；所有开关开启显示对勾，关闭显示 X。
- 快捷指令和文件夹支持预设图标、主题色块，以及连续色相、饱和度、亮度滑条选色。
- 主页标题栏实时搜索、文件夹归类、侧栏导航；快捷指令可复制，副本名称追加 `Copy`。

### Rust 计算核心

支持四则运算、乘方、百分比、`mod`、`gcd`、`lcm`、`abs`、六个三角函数、`sqrt`、`cbrt`、多次方根，以及指定小数位的四舍五入 / 向上 / 向下取整。表达式可以组合变量、函数、括号和常量 `pi`、`e`。

角度单位默认是角度，也可在设置选择弧度或百分度。十进制计算按 34 位有效数字处理；三角函数和开方使用浮点近似并整理输出尾数。普通“计算”中的 `%` 表示左值乘以右值百分比，表达式中的 `%` 表示取余。

统计包括总和、平均、最小、最大、中位数、众数、极差、总体方差和总体标准差。因数操作支持质因数分解、全部正因子和布尔型质数判断，可按 `2^3` 形式显示重复质因数。

### 图像处理与 PDF

图像可以来自系统选择器、相机、分享内容或前面的操作。蒙版、叠放、翻转、拼接、调整尺寸和压缩支持预置参数，也可开启运行时预览并调整。图像信息的宽、高、类型、大小、名称和路径可以分别选作魔法变量。

“制作 PDF”支持文本、图像及混合内容、A4 / Letter、文字分页和图像逐页布局。可以在编辑器指定默认保存目录；没有目录或授权失效时，运行会打开系统保存窗口。截图保存到公共 `Pictures/Screenshots`，输出可继续传入图像操作。

### 自动化与便捷入口

自动化支持指定时间、电量低于阈值、接入 / 断开电源、Wi-Fi 连接、指定 Wi-Fi、网络连接、屏幕开启 / 关闭、开机及 NFC 卡片。选择已保存的快捷指令后，可启用、停用或编辑规则。

桌面小组件提供 1×1、2×2、4×2、4×4 四种布局，分别容纳 1、2、4、8 个快捷指令，运行时显示状态圈。悬浮窗权限允许在屏幕上方显示结果；另有 4 个可绑定的系统快捷设置磁贴。

自动化依赖前台监视服务和系统后台策略。时间规则按分钟匹配，监视服务约每 15 秒检查一次，休眠可能推迟或错过触发。NFC 和指定 Wi-Fi 受硬件、系统派发和权限限制。配置与排查见 [自动化指南](docs/wiki/Automation.md)。

## 开始使用

1. 在 [Releases](https://github.com/AVMLOVER/Shortcuts/releases) 下载并安装 APK，按使用的功能授予权限。
2. 点击主页 `+`，输入名称，添加“文本”，填写 `你好，Shortcuts！`。
3. 添加“快速查看”，内容选择上一步输出，点击播放检查结果，再点击完成保存。
4. 需要处理数据时，在输入框插入变量或选择魔法变量；需要分支时添加“如果”“菜单”或“重复”。
5. 保存后可以从主页运行、加入文件夹、导出 XML，或配置为自动化、小组件、快捷设置入口。

可导入 [示例目录](examples) 中的单个快捷指令 XML，例如 [列表、输入与文件](examples/list-input-files.xml)、[字典与计算](examples/dictionary-calculation.xml)、[共享数字与统计](examples/share-number-statistics.xml)。

更多逐步教程见 [快速上手](docs/wiki/Getting-Started.md) 和 [示例工作流](docs/wiki/Examples.md)。

## 运行模式与权限

| 模式 | 适用场景 | 前提 |
| --- | --- | --- |
| 标准 | 常用数据处理、交互、系统 API、普通 Shell、系统安装器 | Android 常规权限 |
| Shizuku | 以 Shizuku 服务实际身份运行命令、请求安装 APK | 已启动 Shizuku 并授予应用访问权限 |
| Root | Root Shell、特权安装、自定义系统目录读写 | 设备提供 `su`，且已授权应用 |

模式选择只改变执行后端，实际能力以运行时权限为准。自定义系统目录访问目前需要 Root；Shizuku 模式不等于 Root。Shell 默认在软件工作目录运行，执行前查看当前目录和文件列表，对可能写入、删除或无法确认的命令请求确认，并拒绝已识别的根目录批量删除及裸设备写入。

设置提供通知、忽略电池优化、自启动 / 后台、悬浮窗、应用列表、日程读写、相机、相册及位置权限入口。具体用途见 [权限与执行模式](docs/wiki/Permissions-and-Modes.md)。

## 数据、导入与备份

- 快捷指令、设置、自动化规则及草稿保存在应用目录中；常用工作文件放在 `externalFilesDir/workspace`，设置中可查看实际路径。
- 支持单项 XML 导出、设置中的导出全部、主页和设置导入。导入创建独立副本；合集内预设调用会重映射到同批导入的新 UUID。
- XML 为每条快捷指令保存 UUID 和应用版本要求。旧文件自动补齐并原子升级；要求更高版本的文件会提示并拒绝打开。
- 快捷指令导出不包含工作文件、文件夹元数据、自动化、草稿、小组件 / 磁贴绑定和外部文件授权。换机后请重新选择相关文件及目录。
- 日志只在发生未捕获崩溃时落盘，可在设置查看和导出；普通运行不持续写入 trace。

XML 是流程配置。将字典或列表写入工作文件时，应用也可使用有类型的 XML 保存内容，再读取为原类型。详细说明见 [文件与 XML](docs/wiki/Files-and-XML.md)。

## 构建

准备 JDK 17、Android SDK 37.0、Build Tools 37.0.0、NDK `30.0.16248370` 和 Rust。CI 固定 Rust `1.99.1`。在 `local.properties` 设置 `sdk.dir`，并安装四个 Android Rust 目标：

```sh
rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android i686-linux-android
```

Windows：

```powershell
.\gradlew.bat :core:test :app:assembleDebug :app:lintDebug
```

Linux / macOS：

```sh
chmod +x gradlew
./gradlew :core:test :app:assembleDebug :app:lintDebug
```

Debug APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。Gradle 自动调用 Rust / NDK 构建脚本，生成四种 ABI 的原生库。Release 签名配置见 [发布构建说明](docs/BUILD_RELEASE.md)；完整环境、测试和 CI 用法见 [构建与自动编译](docs/wiki/Build-and-CI.md)。

GitHub Actions 在推送 `main`、向 `main` 提交 PR 或手动触发时运行测试、Lint 并生成 Debug / Release 产物；未配置签名 Secrets 时，Release 为未签名 APK。产物保留 14 天，工作流不会自动发布 GitHub Release。

## 使用边界与反馈

这是独立的 Android 项目，操作覆盖以本仓库为准。Android 系统接口、厂商后台管理和特权服务会影响具体行为；不支持导入 Apple `.shortcut` 文件或 iCloud 快捷指令链接。

流程最多配置 1000 个操作、16 层结构嵌套；一次运行及其子调用共享 5000 步预算，调用最多 16 层并拒绝循环调用。列表、字典及文件处理也有容量限制，见 [常见问题](docs/wiki/FAQ.md)。进程被系统结束后，正在执行的流程不会自动恢复。

反馈问题时，请提供应用版本、Android / 系统版本、运行模式、复现步骤，以及可去除个人信息的 XML 或崩溃日志。
